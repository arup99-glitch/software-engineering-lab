# Move Zeroes — LeetCode Solution Explanation

## Problem

Given an integer array `nums`, move all `0`'s to the end of it while maintaining the relative order of the non-zero elements. Must be done **in-place** without making a copy of the array.

**Example 1:**
```
Input:  nums = [0,1,0,3,12]
Output: [1,3,12,0,0]
```

**Example 2:**
```
Input:  nums = [0]
Output: [0]
```

## Code

```cpp
class Solution {
public:
    void moveZeroes(vector<int>& nums) {
        int lastNonZeroFoundAt = 0;
        for(int i = 0; i < nums.size(); i++){
            if(nums[i] != 0){
                nums[lastNonZeroFoundAt++] = nums[i];
            }
        }
        for(int i = lastNonZeroFoundAt; i < nums.size(); i++){
            nums[i] = 0;
        }
    }
};
```

## How it works

Two-pass approach using a single pointer `lastNonZeroFoundAt` that tracks where the next non-zero element should be written.

### Pass 1: Move non-zero elements to the front

```cpp
int lastNonZeroFoundAt = 0;
for(int i = 0; i < nums.size(); i++){
    if(nums[i] != 0){
        nums[lastNonZeroFoundAt++] = nums[i];
    }
}
```

Scans through the array. Whenever a non-zero value is found, it's copied to index `lastNonZeroFoundAt`, then the pointer is incremented.

**Trace for `nums = [0, 1, 0, 3, 12]`:**

| i | nums[i] | Non-zero? | Action | lastNonZeroFoundAt (after) | Array state |
|---|---------|-----------|--------|------------------------------|--------------|
| 0 | 0 | No | skip | 0 | [0,1,0,3,12] |
| 1 | 1 | Yes | nums[0]=1 | 1 | [1,1,0,3,12] |
| 2 | 0 | No | skip | 1 | [1,1,0,3,12] |
| 3 | 3 | Yes | nums[1]=3 | 2 | [1,3,0,3,12] |
| 4 | 12 | Yes | nums[2]=12 | 3 | [1,3,12,3,12] |

After this loop: array is `[1, 3, 12, 3, 12]` (tail is leftover junk), and `lastNonZeroFoundAt = 3` tells us all non-zero elements now occupy indices `0, 1, 2`.

### Pass 2: Fill the rest with zeros

```cpp
for(int i = lastNonZeroFoundAt; i < nums.size(); i++){
    nums[i] = 0;
}
```

Starting from index `3` to the end, everything is overwritten with `0`.

**Final array:** `[1, 3, 12, 0, 0]` ✅

## Why it works

- `lastNonZeroFoundAt` acts as a **write pointer** — always points to the next empty slot for a non-zero value.
- Since the read pointer `i` always moves at the same speed or faster than the write pointer, values are never overwritten before they've been read — this is what makes the in-place compaction safe.
- Relative order is preserved because elements are processed strictly left-to-right, written in the same order encountered.
- The second loop cleans up whatever old values remain after the write pointer's final position.

## Complexity

- **Time:** O(n) — two linear passes over the array
- **Space:** O(1) — only one extra integer variable, no array copy

## Edge case: `nums = [0]`

- Pass 1: `i=0`, `nums[0]==0` → skipped. `lastNonZeroFoundAt` stays `0`.
- Pass 2: `i` starts at `0`, sets `nums[0] = 0`.
- Result: `[0]` ✅ — correct, no crash since loop bounds remain valid.
